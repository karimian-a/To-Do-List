# To-Do List

A simple and lightweight To-Do List web application built with HTML, CSS, and JavaScript.

## Live Demo

[View the deployed project](https://karimian-a.github.io/To-Do-List/)

## Features

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Save tasks using Local Storage
* Preserve task status after refreshing the page
* Simple and clean user interface

## Technologies

* HTML5
* CSS3
* JavaScript
* Local Storage API

## How It Works

Tasks are stored in the browser using the **Local Storage API**. This allows the application to preserve both the tasks and their current status after the page is refreshed or reopened.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/karimian-a/To-Do-List.git
```

Open the project directory:

```bash
cd To-Do-List
```

Then open `index.html` in your browser.

## Purpose

This project was built as a JavaScript practice project to work with DOM manipulation, events, arrays, functions, and browser Local Storage.
